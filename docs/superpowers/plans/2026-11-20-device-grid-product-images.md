# Rencana Implementasi Grid Perangkat

1. Siapkan lima PNG transparan bertema maroon, gold, dan ivory untuk empat lampu serta satu pompa.
2. Daftarkan folder aset perangkat pada `pubspec.yaml`.
3. Ubah panel Perangkat menjadi grid dua kolom berisi lima kartu dengan nama singkat, status, gambar produk, dan toggle.
4. Pertahankan aksi kartu dan koneksi toggle ke detail serta layanan ESP32 yang sudah ada.
5. Hapus kartu pompa lebar, ringkasan jumlah lampu, dan footer estimasi lama.
6. Format kode dan jalankan Flutter analyzer.
